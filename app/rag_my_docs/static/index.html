Ask the IRS publications

Questions are answered from 12 IRS publications for tax year 2025, and from nothing else:

  1. Embed the question into a vector, with the same local model as the passages.
  2. Retrieve the passages whose vectors are closest to it.
  3. Prompt a language model with those passages and the question.
  4. Answer from the passages alone, citing the ones used.

A question no passage is close to is answered "not covered", without calling the model. Check the cited page before relying on an answer.

Or try one:

    More passages: a better chance the answer is among them, but a longer prompt, slower and costlier, with more text the model must ignore.
